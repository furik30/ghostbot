# 👻 GhostBot

Умный Userbot для Telegram на базе Google Gemini. Работает через черновики, сохраняя полную анонимность автоматизации.

**Примечание:** Это dev-ветка для разработки и тестирования новых функций. Для стабильной версии используйте основную ветку.

## 🚀 Быстрая установка

Запустите эту команду на вашем сервере (Ubuntu/Debian):

```bash
bash <(curl -sL https://raw.githubusercontent.com/furik30/ghostbot/dev/install.sh)
````

Скрипт автоматически:

1. Установит Docker и Git.
2. Запросит API ключи (Telegram & Gemini).
3. Запустит авторизацию (введите номер и код из SMS).
4. Установит команду `ghostbot`.

## 🎮 Управление

После установки используйте команду `ghostbot` из любой папки:

|**Команда**|**Описание**|
|---|---|
|`ghostbot logs`|Смотреть логи в реальном времени|
|`ghostbot restart`|Перезагрузить бота|
|`ghostbot update`|Обновить версию (git pull + rebuild)|
|`ghostbot edit-env`|Изменить API ключи|
|`ghostbot edit-prompts`|Редактировать промпты|
|`ghostbot status`|Проверить статус контейнера|
|`ghostbot login`|Повторная авторизация (если слетела сессия)|

## ⚙️ Функционал

**Основные команды:**
- `.r (или .к) [кол-во] [стиль 1-3]` — Сгенерировать ответ (сохраняется в черновик).
- `.rf` — То же, но отправляет ответ **сразу в чат**.
- `.fix [текст]` — Исправление текста (сохраняется в черновик).
- `.ff [текст]` — Исправить и отправить **сразу в чат**.
- `.roast` — Шуточная "прожарка" участников (результат в Saved Messages).
- `.roastf` — "Прожарка" с отправкой **сразу в текущий чат**.
- `.ask [кол-во] [вопрос]` — Запрос к AI-ассистенту (ответ в черновик). Если указано число, учитывает контекст переписки.
- `.askf` — То же, но отправляет ответ **сразу в чат** (с подписью "🤖 Ответ нейросети").

**Аналитика и утилиты:**
- `.e (или .explain) [кол-во]` — Саммари переписки и объяснение терминов/сленга.
- `.p (или .prompt) [текст]` — Профессиональное написание промпта для нейросети.
- `.vtt (или .гс)` — Расшифровка голосовых и видеосообщений в текст (результат в Saved Messages).
- `.vttf (или .гсf)` — То же, но отправляет расшифровку **сразу в чат**.
- `.mimi [кол-во]` — Анализ профиля собеседника (Mimicry).
- `.memo [текст]`: Сохранение заметки по чату (Context Memory).
- `.memoshow`: Просмотр текущей заметки.

## 📁 Структура проекта

Проект состоит из следующих ключевых компонентов:

- **`main.py`** — Главный файл приложения, точка входа в программу.
- **`config.py`** — Конфигурационный файл для настроек бота.
- **`prompts.yaml`** — Файл с промптами для различных функций бота.
- **`requirements.txt`** — Список зависимостей Python.
- **`Dockerfile`** и **`docker-compose.yml`** — Файлы для контейнеризации приложения с помощью Docker.
- **`install.sh`** и **`ghostbot.sh`** — Скрипты для установки и управления ботом.
- **`modules/`** — Директория с модулями функционала.
- **`utils/`** — Вспомогательные утилиты:
  - `gemini_api.py` — Интеграция с Google Gemini API.
  - `logger.py` — Логирование.
  - `common.py` — Общие функции.

## 🔧 Инструкции по работе

Для локальной разработки:

1. Клонируйте репозиторий: `git clone https://github.com/furik30/ghostbot.git`
2. Перейдите в ветку `dev`: `git checkout dev`
3. Установите зависимости: `pip install -r requirements.txt`
4. Настройте переменные окружения на основе `.env.example`
5. Запустите бота: `python main.py`

Для внесения изменений следуйте инструкциям в разделе "Вклад".
